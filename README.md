# Titanic Survival Analysis 🚢

A data analysis project exploring survival patterns in the Titanic dataset.
Built as part of a Data Science internship task.

## Project Overview
This project analyzes the famous Titanic dataset to uncover what factors
determined whether a passenger survived. Using Python, Pandas, and Matplotlib,
we explore the role of gender, passenger class, and age in survival rates.

## Dataset
- **Source:** [Kaggle - Titanic Dataset](https://www.kaggle.com/competitions/titanic)
- **Size:** 891 passengers, 12 features

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Findings
- **Gender** was the strongest survival factor — females survived at 74% vs 19% for males
- **Passenger class** directly determined survival — 1st class (63%) vs 3rd class (24%)
- **Children** had the highest survival rate (58%) among all age groups
- A 3rd class male had ~15-18% chance of survival vs ~95% for a 1st class female
